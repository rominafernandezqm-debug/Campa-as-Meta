# Clientes en Piloto Automático

Negocio digital: un kit de Meta Ads + prompts de IA para entrenadores personales y coaches de bienestar.

## Contenido del repositorio

| Archivo | Qué es |
|---|---|
| [`plan-de-negocio.md`](plan-de-negocio.md) | Idea, cliente ideal, oferta, herramientas, plan de 30 días y números |
| [`landing/index.html`](landing/index.html) | Landing page de venta, lista para publicar |
| [`contenido/emails-bienvenida.md`](contenido/emails-bienvenida.md) | Secuencia automática de 5 emails |
| [`contenido/posts-redes.md`](contenido/posts-redes.md) | 2 semanas de contenido para Instagram/TikTok |
| [`plan-visual.html`](plan-visual.html) | El plan de negocio en versión visual, con checklist de 30 días |
| [`lead-magnet/10-prompts-anuncios-fitness.pdf`](lead-magnet/10-prompts-anuncios-fitness.pdf) | Regalo gratis: 10 prompts de IA (PDF listo para subir a MailerLite) |
| [`lead-magnet/10-prompts.html`](lead-magnet/10-prompts.html) | Fuente del PDF. Para regenerarlo: `node lead-magnet/generar-pdf.js` |

## Antes de publicar la landing
Busca los comentarios `TODO` en `landing/index.html` y completa:
1. Tu foto, nombre e historia.
2. El link de pago (Hotmart o Gumroad).
3. El formulario de MailerLite.
4. Testimonios reales (cuando los tengas).

## Publicar gratis con GitHub Pages
En GitHub: **Settings → Pages → Deploy from a branch**, elige la rama y la carpeta `/ (root)`.
La página quedará en `https://<tu-usuario>.github.io/Campa-as-Meta/landing/`.
